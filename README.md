# Diabetes-Patient-Insights-Dashboard-Risk-Glucose-Control-Lifestyle-Drivers-
Diabetes Patient Insights Dashboard using Python and Machine Learning. Analyzed 100,000 patient records, explored clinical and lifestyle risk factors, performed EDA, and developed classification models with hyperparameter tuning to predict diabetes status and support early risk identification.
Diabetes Risk Assessment and Prediction Using Machine Learning

Project Overview

This project focuses on predicting diabetes risk using machine learning algorithms.

Dataset

* Dataset Name: Diabetes Prediction Dataset
* Total Records: 100,000
* Total Features: 33

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

Data Preprocessing

* Handling missing values
* Removing duplicate records
* Label Encoding
* Outlier detection using IQR

Machine Learning Algorithms

* Logistic Regression
* Decision Tree
* Random Forest
* KNN
* Gaussian Naive Bayes
* Gradient Boosting
* XGBoost
* SVM
* AdaBoost

Project Outcome

Developed machine learning classification models to predict diabetes risk and evaluate their performance.
